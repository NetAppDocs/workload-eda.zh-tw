= 在 Workload Factory for EDA 中啟動 Overview 儀表板
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
啟動概覽儀表板，即可開始收集 FSx for ONTAP 檔案系統的 CloudWatch 指標。此儀表板可讓您在一個位置查看叢集運作狀況、容量和吞吐量。



[[before-you-begin]]
== 開始之前

在啟動儀表板之前，請確保您符合下列要求。



[[aws-credentials-with-view-permissions]]
=== 具有檢視權限的 AWS 憑證

您必須在 Workload Factory 中設定 AWS 認證資料、並至少具備 General Storage 的讀取（檢視）權限。不支援 _Basic_ 認證資料。

如果您尚未設定具有檢視權限的認證資料，則開啟「概覽」標籤時，您將被重新導向至 AWS 認證資料設定頁面。

如果您尚未配置 AWS 憑證，請參閱 link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["新增 AWS 憑證"^]。



[[activate-the-dashboard]]
== 啟動儀表板

Workload Factory 驗證憑證並確認其具有檢視權限後，即可啟動儀表板，開始收集 CloudWatch 指標，以供您的 FSx for ONTAP 檔案系統使用。


NOTE: 您同意後，收集指標可能需要一些時間。控制面板會在首次收集過程中通知您。

.步驟
. 使用以下任一方式登入 link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主機體驗"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示"]，然後選擇 *EDA*。
. 選擇 *Overview* 標籤。
. 如果未偵測到具有檢視權限的憑證，請選擇 *Add credentials*，然後依照提示配置具有檢視權限的 AWS 憑證。之後返回 *Overview* 選項卡。
. 請查看同意提示，其中描述了將為您的 FSx for ONTAP 檔案系統收集的 CloudWatch 指標。
. 選擇 *Activate* 以啟動儀表板並開始收集指標。


.結果
Workload Factory 開始收集與您的 AWS 憑證關聯的所有 FSx for ONTAP 檔案系統的 CloudWatch 指標。指標資料可用時，控制面板會更新。資料收集仍在進行時，會顯示通知。
